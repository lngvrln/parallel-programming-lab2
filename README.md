# Домашнее задание: SIMD-инструкция
- Номер в eclass: N = 7
- Вариант: v = ((7 − 1) mod 24) + 1 = **7**
- Инструкция: **`_mm_add_ps`** (строка `_mm, _ps`, столбец `_add`)

## Что делает программа
Поэлементное сложение двух массивов `float`: `c[i] = a[i] + b[i]`.
`_mm_add_ps` складывает сразу 4 числа `float` одной командой (SSE).

## Как реализовано
- Основная часть (кратная 4) обрабатывается через `_mm_add_ps`.
- Остаток `n % 4` (тест с n = 1003) обрабатывается скалярным циклом.
- Выравнивание: если все три массива выровнены на 16 байт — `_mm_load_ps/_mm_store_ps`,
  иначе `_mm_loadu_ps/_mm_storeu_ps`. Память выделяется через `aligned_alloc(16, ...)`;
  во втором тесте указатели сдвигаются на 1 элемент, чтобы проверить невыровненный случай.
- Результат сверяется со скалярным циклом, выводится максимальная абсолютная ошибка
  (для сложения она равна 0: SSE-сложение float даёт тот же результат по IEEE-754).
- Программа неинтерактивная, печатает номер, вариант, имя инструкции и результат.
